# Gushi 记忆注入 A/B 前后对比分析报告（多故事版）

> 测试日期：2026-08-17 | 测试人：肖文宇 | 环境：Docker (gushi-app + postgres)
> 版本：v2（多故事 + 量化指标）

---

## 一、测试目的

验证"叙事状态表 + 知识图谱"注入对故事续写的效果。相比第一版单故事测试，本版：
1. **扩大到 2 个不同背景的故事**（桃园结义 / 张骞出使西域）
2. **增加客观量化指标**：Prompt注入差 / 相邻段重复度 / 图谱状态表增长
3. 结合量化指标 + 人工阅读，做综合分析

## 二、测试方法

| 项 | 说明 |
|----|------|
| A组（基线） | 关闭记忆注入（`MEMORY_MODULES_ENABLED=false`），原始 Prompt 续写 |
| B组（新方法） | 开启状态表+图谱注入，续写 |
| 每组 | 连续续写 3 段，独立分支，共享同一起始段 |
| 故事1 | 桃园结义（4角色：刘备/关羽/张飞/董卓，多关系：结拜/敌对） |
| 故事2 | 张骞出使西域（3角色：张骞/汉武帝/匈奴单于，主线单角色） |
| 量化指标 | ① Prompt注入差 ② 相邻段 trigram 相似度（重复度）③ 图谱节点/边增长 ④ 状态表对象数 |

## 三、量化结果

| 指标 | 故事1·桃园结义 | 故事2·张骞出使西域 |
|------|--------------|------------------|
| **Prompt 注入差** | **+954 字**（A=2120 → B=3074） | **+881 字**（A=2111 → B=2992） |
| **相邻段重复度**（越低越好） | A=0.025 → **B=0.014**（**降低 44%** ✅） | A=0.020 → B=0.021（持平 ⚠️） |
| **图谱增长**（B分支续写后） | 57→74 节点，61→87 边 | 86→103 节点，95→118 边 |
| **状态表追踪**（B分支） | 18 个对象 | 9 个对象 |

> 两个故事都证明：**记忆系统在真实生成链路中自动工作**——续写 3 段后知识图谱自动增长（桃园 +17 节点，张骞 +17 节点），状态表持续追踪对象。

## 四、内容对比（人工阅读）

### 故事1·桃园结义

**A组（无注入）**：结义盟誓 → 行至中牟遇流民报董卓劫掠 → 至陈留观天象议局势
- 每段都在**换地点**（桃园→中牟→陈留），靠"转移场景"推进，动作性偏弱
- 段3"观天象+引典"议论为主，角色各说一句话，缺乏具体行动

**B组（有注入）**：结义后各自表态 → **三人分头行动**（刘备募义士 / 关羽打造青龙偃月刀 / 张飞设寨练兵）→ 细作报来**具体敌情**（李傕郭汜各领三千骑、相距三十里、营中防守稀疏）

- ✅ **角色分工明确**：段2三个角色各司其职，呼应在状态表中的 role/goal（张飞"设栅立寨操练"呼应 mood=激昂；刘备"募义士"呼应 goal=兴复汉室）
- ✅ **敌情具体**：段3的军事情报有具体人物、数字、地形，知识图谱的关系结构提供了细节锚点
- ✅ **情节层层递进**：表态→准备→接敌情，因果链条清晰

### 故事2·张骞出使西域

**A组（无注入）**：出陇西被擒 → 被软禁，单于以声色诱之，张骞持节不屈 → 牧羊北海，单于诱降，张骞默画西域地图

**B组（有注入）**：出陇西遇匈奴游骑，结阵自守持节厉声 → 被留匈奴赐胡妻，每晨持节望南拜 → 佯为恭顺，心愈坚，默诵诗经

- 两组质量都较高，B 组在"持节"细节上更丰富（"手中汉节虽旄毛尽落犹朝夕摩挲"→"每晨整衣冠持节望南拜"）
- 但**整体差异不明显**，量化指标也印证（相似度 A=0.020 vs B=0.021 持平）

## 五、分析结论

### 1. 记忆注入在生成链路中真实生效（两个故事一致）
- Prompt 稳定增加约 900 字的结构化记忆（状态表 + 图谱关系）
- 续写过程中知识图谱自动增长（每故事 +17 节点），状态表持续追踪
- 这是"代码从写了到用了"的直接证据

### 2. 效果强弱与故事结构强相关
| 故事特征 | 例子 | 注入效果 |
|----------|------|----------|
| **多角色互动 + 多关系边** | 桃园结义（4角色，结拜/敌对关系网） | **明显**（重复度降44%，分工动作清晰） |
| **单主角线 + 关系简单** | 张骞出使西域（主角独自坚持） | **有限**（两组质量都高，差异小） |

**解释**：状态表/图谱的核心价值是约束"多个实体之间的关系和状态"。桃园结义里刘备/关羽/张飞/董卓之间关系多、可约束的点多，注入价值大；张骞故事基本是单人内心戏，可约束的关系少，注入边际价值低。

### 3. 相邻段重复度指标（trigram 相似度）说明
- 绝对数值都很低（0.01~0.03），因为中文长文本相邻段天然差异大
- 做**相对比较**有意义：桃园 A=0.025 vs B=0.014（B 降低 44%），说明 B 组情节更不套模板
- 张骞持平（0.020 vs 0.021），与人工阅读一致

## 六、局限与下一步

**局限：**
- 样本仍小（2 故事 × 每组 3 段），统计意义有限
- trigram 相似度只测"字面重复"，测不出更深层的语义重复
- 未做双打分（人工+AI）的量化

**下一步建议：**
1. 扩大样本：每个故事配置跑 5+ 个，覆盖多角色/单角色两类
2. **重点在多角色故事上验证**（如三国群像、团队冒险），这是记忆注入的主场
3. 双打分落地：黄夏薇 LLM-as-Judge + 喻荣海人工打分，按五维（角色一致性/情节连贯/关系一致/史实准确/趣味性）量化
4. 探索语义级重复检测（如 embedding 相似度）替代字面 trigram
