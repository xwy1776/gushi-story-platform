### 三-1、为什么「相邻段重复度」不能直接比：退化复读

本指标实测为**双峰分布**：绝大多数相邻对相似度在 0.01–0.15（正常续写），
但会出现相似度 1.00 的相邻对——检查原文，这些段落是**逐字节完全相同**的，
即模型整段照抄了上一段，而不是"情节套路化"。

它会把均值彻底带偏，原因是两个放大机制：

1. **一个触发点贡献多个 1.00**。照抄出来的文本又成为下一段的"上文"，模型会继续照抄
   （吸收态），所以第 3/4/5 段全同时，4 个相邻对里有 2 个是 1.00，该故事均值从 ~0.05 抬到 ~0.5。
2. **n 太小**。n=5 故事时，一个故事触发就把该档均值抬高约 0.1，超过档间真实差异。

已验证这不是台架 bug：逐步打印 Prompt 哈希与正文哈希，复读发生时相邻两步的
**Prompt 内容与长度都不同**，输出却逐字节相同；且同一 Prompt 连调三次输出互不相同
（采样是随机的）。诊断脚本：[scripts/repro-repeat.ts](../scripts/repro-repeat.ts)。

**结论**：退化复读是模型侧的固有失效模式，与记忆档位无关（`none` 与 `graph` 在同一故事上
同样触发），发生率约 5%/步。因此它应当**单独作为一个指标报告**（退化复读率），
而不是混进"重复度均值"里当作被解释变量。
