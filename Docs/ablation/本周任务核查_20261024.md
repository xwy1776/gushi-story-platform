- 规模：20 组 × 2 档 × 5 段 × 3 轮 = 600 段；

## 四、RAG 外部基线当前做到哪

新增三档：

| 档位 | 含义 |
|---|---|
| `isolated` | 本文分支隔离 |
| `shared` | 内部单线强泄漏对照 |
| `rag` | 单线共享检索池 + top-k 注入 |

`rag` 会：

1. 把 A、B 的事实和共享 opener 放入同一检索池；
2. 用 opener + 当前尾段检索 top-3；
3. 关闭内置状态表/图谱；
4. 把新生成段落写回检索池。

正式跑批命令：

```bash
npx tsx tests/ab_branch_isolation.ts \
  --stories=20 --segments=5 --rounds=3 \
  --arms=isolated,shared,rag \
  --tag=rag20
```

smoke 被本机环境挡住：Docker Desktop 的运行时 socket 损坏，PostgreSQL 5433 未启动。
已经修复了 `AppData\Local\Docker\run\dockerInference`，随后又发现
`docker-secrets-engine\engine.sock` 同类损坏；该目录当前无法被 Windows 删除或改名。
这不是代码失败，需要用 Docker Desktop 的修复/重置或重启系统后再跑。
