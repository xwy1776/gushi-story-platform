## 一、为什么必须做这个实验

4 档消融（`ab_ablation.ts`，见 [论文_实验与结果_草稿.md](论文_实验与结果_草稿.md)）证明的是
**「记忆注入有用」**。但 SCORE(2025.03) 和 DOME(2024.12) 也是记忆系统，**它们同样能证明这件事**。

本文相对它们的唯一增量是**分支感知（branch-aware）**：同一角色在不同分支处于不同状态时，
记忆按 `branchId` 隔离。而那个消融的每个故事**只跑单一分支**，本质是线性续写任务 ——
**它在结构上就测不到分支感知**。

在跑这个实验之前，支撑"分支感知"的只有单元测试级证据（同一角色在两分支状态不同、
写 B 分支不污染 A 分支）。单元测试能证明**机制正确**，证明不了**效果**。

> 审稿人几乎必然会问："你声称分支感知是核心创新，那么分支感知的实验在哪里？"
> 这个实验就是那个答案。**它决定论文的主线能不能成立**——如果隔离开/关两档没有差异，
> 论文就失去了唯一的增量贡献。这与"扩样本量"那种降低风险的实验性质不同。

## 二、设计

### 2.1 场景

对 5 个故事各造一个分叉点，两条**设定互斥**的分支甲 / 乙。例如桃园结义：

| | 设定 | 记忆里的事实 |
|---|---|---|
| **分支甲** | 投公孙瓒，借兵讨董 | 刘备驻**北平**，盟友公孙瓒，借兵三千 |
| **分支乙** | 投曹操，会盟讨董 | 刘备驻**许都**，盟友曹操，会盟讨董 |

**只在分支甲上续写 5 段。**

### 2.2 两档对照

| 档位 | 做法 | 对应现实中的系统 |
|---|---|---|
| `isolated` | 甲的事实挂 `branchId=甲`，乙的事实挂 `branchId=乙` → 甲的检索看不见乙 | **本文做法** |
| `shared` | 甲、乙的事实**都**挂到甲的检索空间 | **SCORE / DOME 式单线记忆**（一个故事只有一份记忆，没有分支维度） |

`shared` 档刻意**不去改库代码**：把乙的事实也塞进甲的检索空间，正是"没有分支维度"的
系统自然会发生的事——它的记忆池里同时躺着两套互斥设定。

### 2.3 指标与主估计量

**跨分支污染率** = 甲分支续写段落中，采用了乙分支独有事件/状态的段落占比。

> ⚠️ **不要直接比较两个绝对污染率。** 隔离开着也会测出非零污染，因为模型的**世界知识**
> 本身就会产出与乙相似的桥段（三国题材里"刘备与曹操会盟"是史实，不靠注入也会写）。
> 那是先验，不是泄漏。

**主估计量 = 单线档污染率 − 隔离档污染率**（净泄漏增量）。隔离档在这里的作用是
**扣掉模型先验的对照**，不是"应该等于 0 的期望值"。

用两个**互相独立**的度量，并报告一致率：

| 度量 | 做法 | 性质 |
|---|---|---|
| 关键词法 | 段落是否命中乙分支的专属措辞 | 客观、可复算、便宜，但**粗**（见 §四） |
| LLM-as-Judge | 把甲/乙设定 + 正文给模型判定 | 能处理语义与改写，**主判定** |

之所以要两个：本项目已经吃过一次「指标静默失效」的亏（见 [退化复读诊断.md](退化复读诊断.md)），
单一指标的结论不可信。

## 三、⚠️ 试跑揪出的四个设计缺陷

这一节是本文档最有价值的部分。**四个缺陷都是在正式跑之前、用小样本试跑发现的**，
而且每一个都足以让结论完全反转。记下来是因为它们都是"看起来合理但实际在测别的东西"的典型。

### 缺陷 ①：分叉点 opener 把两个选项都写出来了

最初的分叉点片段写成：

> "…摆在三人面前的有两条路：**是北上投奔公孙瓒借兵，还是东行投奔曹操会盟**？刘备沉吟良久…"

**两档共见这段 opener**，于是乙分支的地名（许都）和人名（曹操）从一开始就在上下文里，
模型自然照写。结果 `isolated` 档测出 50% 污染率 —— **那是 opener 泄漏，不是记忆泄漏**。

**改法**：opener 停在分叉点上，**刻意不写任何一条分支的去向**。分支必须**只由注入的记忆决定**。

```diff
- …摆在三人面前的有两条路：是北上投奔公孙瓒借兵，还是东行投奔曹操会盟？刘备沉吟良久，终于做出决断。
+ …欲讨董卓，必先得一强援。刘备在中军帐中展开舆图，久久不语——投奔何人、屯驻何地，这一步走错，三人便再无翻身之日。
```

改完后 `isolated` 档从 50% 降到 0~33%（剩下的部分是模型先验，见 §2.3）。

### 缺陷 ②：拿著名历史人物当标记词

最初把「曹操」列为分支乙的标记词。但**曹操在三国题材里是常识**，模型凭空写出来
不代表记忆泄漏。实测 `isolated` 档第 2 段编了个曹操客串（"原来曹操自陈留起兵…特来相会"），
关键词法立刻判污染 —— **假阳性**。

**改法**：标记词**只用地点/事件专有名词**（北平、许都、督亢、辽东…），不用人物名。
并把这条规则写进代码注释，防止后人改回去。

### 缺陷 ③：标记词是通用词

一度把「会盟」「退守」「娶妻」「固守」当标记词。这些都是**通用叙述词**：
"诸侯会盟讨董"是三国故事的背景常识，模型写它跟分支无关。实测 `isolated` 档
三段全部命中「会盟」，Judge 全判干净 —— **关键词法 100% 假阳性**。

**改法**：同 ② —— 专有名词优先。这条经验与 ② 合并成"挑词两条规则"写进了代码。

### 缺陷 ④：LLM-as-Judge 的采样温度没锁

Judge 最初走默认的题材温度推断，拿到 **0.5**。同一段文本两次判定可能给出相反结论 ——
**度量工具本身是随机的**，这对主指标是致命的。

**改法**：给 `callAIText` / `callAI` / `buildOpenAIRequest` 加了 `temperature` 覆盖参数
（默认行为不变），判定调用显式传 `0`。

```ts
const raw = await callAIText(prompt, { maxTokens: 300, temperature: 0 });
```

### 附：两个台架 bug

- **段 id / 分支 id 是模块级常量**（`seg_fork_main_000`、`branch_fork_A`），
  所有故事共用 → 第二个故事 setup 时撞 Prisma 唯一键直接崩（P2002）。
  改成一律带故事名。**同一个坑踩了两次**（段 id 修完，分支 id 又犯），
  第二处修完顺手给每个"故事×档位"加了 try/catch，避免单点失败拖垮整轮。
- 试跑脚本用 `| head -N` 截断输出，管道关闭触发 SIGPIPE 把进程杀掉，**JSON 没落盘**，
  白跑一轮还看不出原因。长时间跑批一律写日志文件，不接 `head`。

## 四、关键词法的失效模式（为什么它只作佐证）

实测两法分歧很大，且**两个方向的错都出现过**：

| 方向 | 例子 |
|---|---|
| **假阳性** | 荆轲刺秦的「蓟城」「辽东」是燕国地名，属常识。`isolated` 档照常提到，关键词法判 100% 污染，Judge 判 0% |
| **假阴性** | 桃园结义 `shared` 档写"欲往许都投曹孟德"命中「许都」；但同档也有段落用"投曹公""往依之"等改写表达，一个标记词都不命中 |

**词面重合与"主角是否真的进了乙分支的设定"是两件事。** 关键词法便宜、可复算，
适合当粗筛；判定必须看 Judge。报告里两列并列，正是为了让这个分歧可见 ——
而不是把关键词法包装成一个有效指标。

> 这一节是刻意写的。本项目已经因为「一个看起来合理的指标其实在测别的东西」
> 吃过一次大亏。所以引入新指标时把它的失效模式一并写明，而不是只报对自己有利的那一列。

## 五、结果

> ⚠️ 计划 3 轮，实际拿到 **2 轮**（第 3 轮跑到一半 DeepSeek 余额耗尽）。
> 数据完整性说明见 **§5.4 —— 必读**。

### 5.1 试跑（3 组 × 2 档 × 3 段 × 1 轮，仅用于验证设计与看信号）

| 故事 | 隔离档 Judge 污染率 | 单线档 Judge 污染率 |
|------|------:|------:|
| 桃园结义 | 33% | **100%** |
| 张骞出使西域 | 0% | **67%** |
| 荆轲刺秦 | 0% | **100%** |
| **平均** | **11%** | **89%** |

**净泄漏增量 ≈ 78 个百分点。** 单线档的污染是压倒性的、字面可查的：

```
桃园结义 shared 段2：某乃涿郡刘备，欲往许都投曹孟德共讨董卓；遂与赵云拱手作别，随夏侯惇望许都进发。
桃园结义 shared 段3：玄德整冠束带，引关、张入许都。城门大开…曹操亲率文武出迎。
荆轲刺秦 shared 段1：燕王喜退保辽东，蓟城遂陷。……燕王喜遂据辽水之险，收合余烬，聊以自保。
张骞出使西域 shared 段2：居岁余，胡妇携幼子来北海…（乙分支的"娶妻生子"设定）
```

而隔离档那 33%（桃园段 2）的证据是"刘备与曹操并辔而行，望酸枣进发"——
opener 里**根本没提曹操或许都**，这是模型的世界知识，属先验基线，不是泄漏。

**结论（试跑）**：设计与指标都能用，信号方向明确且幅度大。样本量（3 组 × 3 段）远不足以
下最终结论，正式跑见 5.2。

### 5.2 正式结果（3 轮）

**5 组冲突分支 × 2 档 × 5 段 × 3 轮**（共 150 段续写 + 150 次 Judge）：

| 档位 | 关键词法污染率 | **Judge 法污染率** | 两法一致率 | 各轮 Judge |
|------|------:|------:|------:|------|
| **分支隔离（本文）** | 29% | **13%** | 60% | 8% / 8% / 24% |
| **单线记忆（SCORE/DOME 式）** | 48% | **37%** | 73% | 32% / 48% / 32% |

### ➜ 净泄漏增量 = **24 个百分点**

| 故事 | 分支甲 | 分支乙 | 隔离档 | 单线档 | 谁更好 |
|------|------|------|------:|------:|:---:|
| 桃园结义 | 投公孙瓒，借兵讨董 | 投曹操，会盟讨董 | 60% | 80% | ✅ 隔离 |
| 张骞出使西域 | 持节不屈，伺机西逃 | 受胁迫留居匈奴 | 0% | 0% | — 持平 |
| 荆轲刺秦 | 献督亢地图求和 | 退守辽东 | 7% | 87% | ✅ 隔离 |
| 赤壁之战 | 联刘抗曹 | 纳降曹操 | 0% | 20% | ✅ 隔离 |
| 郭子仪单骑退敌 | 单骑入回纥营结盟 | 固守泾阳待援 | 0% | 0% | — 持平 |

配对 t 检验（配对单位=故事，n=5）：

```
逐故事差值（单线−隔离）= [0.20, 0, 0.80, 0.20, 0]
均值 0.240   标准差 0.329   SE 0.147
t = 1.63     df = 4     双尾临界值 2.776   → 未达显著
```

#### ⚠️ 5.2-1 两轮时是 32pp / t=2.09，加到三轮后掉到 24pp / t=1.63

这个变化必须写进来，不能只报好看的那一版：

| | 2 轮（08:21 / 08:32） | 3 轮（+ 09:15） |
|---|---:|---:|
| 净泄漏增量 | 32 pp | **24 pp** |
| 配对 t | 2.09 | **1.63** |

第 3 轮的隔离档明显更脏（24%，前两轮都是 8%），几乎全部来自桃园结义一格（见下）。
**「24pp 是不是稳定估计」目前无法回答** —— 2 轮 32pp、3 轮 24pp，不确定性还很大。

#### ⚠️ 5.2-2 「从不更差」在轮级有 1 处反例

聚合到故事级是 3 胜 2 平 0 负。但**逐轮拆开看，15 个「故事×轮」格里有 1 个反转**：

| 故事 | 轮 1 | 轮 2 | 轮 3 |
|------|:---:|:---:|:---:|
| 桃园结义 | 40 / 100 | 40 / 80 | **100 / 60** ⚠️ |
| 张骞出使西域 | 0 / 0 | 0 / 0 | 0 / 0 |
| 荆轲刺秦 | 0 / 60 | 0 / 100 | 20 / 100 |
| 赤壁之战 | 0 / 0 | 0 / 60 | 0 / 0 |
| 郭子仪单骑退敌 | 0 / 0 | 0 / 0 | 0 / 0 |

（格式：隔离档 % / 单线档 %）

**桃园结义轮 3**：隔离档 100%、单线档 60%。看正文可以解释——隔离档那一轮模型反复
回到"刘备与曹操"这条史实路线（§2.3 说的先验知识），而同一轮的单线档反而写偏了别的方向。
**这是先验噪声，不是隔离失效**，但它足以说明：

> **不能宣称"隔离档从不更差"。** 准确说法是"在 5 个故事 3 轮共 15 个格中，隔离档有
> **1 格**反超单线档，其余 14 格持平或更好"。样本量小的时候，任何"从不/总是"
> 的强断言都会被一格反例打掉。

### 5.3 两个故事为什么没有差异

张骞出使西域、郭子仪单骑退敌，三轮六格全部 0% / 0%。看设定就能理解：

- **郭子仪**：甲（单骑入回纥营结盟）与乙（固守泾阳待援）都是"在泾阳附近做决定"，
  地点不冲突、人物不冲突，模型写哪个都不算越界
- **张骞**：甲（西逃大宛）与乙（留居匈奴王庭）虽有地点差异，但"张骞在匈奴"是共同前提，
  模型写"胡妇携幼子"时未必是在采纳乙分支的状态，也可能是自由发挥

**含义**：跨分支污染只在**两条分支给出"互相排斥且都很具体的目的地"**时才明显。
这既是本实验的边界条件，也说明**冲突分支的设计本身是实验效度的一部分**——
"甲去 A 地 / 乙去 B 地"这类设定信号最强。

### 5.4 结论：当前能说的与不能说的

**✅ 能说**：

1. 单线记忆系统下，分支甲的续写有 **37%** 的段落采用了分支乙的设定；分支隔离压到 **13%**，
   差值 **24 个百分点**。
2. **方向在 3 轮上完全一致**：隔离档 8% / 8% / 24%，全部低于单线档 32% / 48% / 32%。
3. 逐故事聚合为 **3 胜 2 平 0 负**。
4. 污染在正文层面**字面可查**，不做任何判定也能看出来：

   ```
   荆轲刺秦 shared：燕王喜退保辽东，蓟城遂陷。……燕王喜遂据辽水之险，收合余烬，聊以自保。
   赤壁之战 shared：孙权纳降，江东归附曹操。
   桃园结义 shared：玄德整冠束带，引关、张入许都。城门大开…曹操亲率文武出迎。
   ```

**❌ 不能说**：

1. **"显著优于"** —— t = 1.63，远低于 2.776。
2. **"从不更差"** —— 15 格里有 1 格反转（桃园轮 3）。
3. **把 24pp 当稳定估计** —— 2 轮时是 32pp。效应量的不确定性还很大。

**要变成硬结论，需要**：把冲突分支扩到 **10–12 组**（配对单位是**分支对**，不是轮次——
加轮次只降噪不增样本量），且优先选"甲去 A 地 / 乙去 B 地"这类强冲突设定（§5.3）。

> 📌 **一句话给论文用**：分支隔离在 3 轮 × 5 组冲突分支上把跨分支事实泄漏从 37% 压到 13%，
> 方向三轮一致、逐故事 3 胜 2 平，但 **n=5 未达统计显著，且存在 1 处轮级反例**，
> 因此只能作为**方向性证据**，不能作为显著性主张。

  ```bash
  # 跨分支补第 3 轮，再重出汇总
  npx tsx tests/ab_branch_isolation.ts --stories=5 --segments=5 --rounds=1
  npx tsx tests/ab_branch_isolation.ts --report-only

  # 消融扩样 15 故事 × 3 轮（每轮一次调用），再只看扩样那几轮的汇总
  npx tsx tests/ab_ablation.ts --stories=15 --segments=5      # 重复 3 次
  npx tsx tests/ab_ablation.ts --rounds-report --only=s15x5seg --out=s15_rounds_report.md
  ```
