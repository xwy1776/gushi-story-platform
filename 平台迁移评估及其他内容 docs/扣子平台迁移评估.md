# 项目迁移至扣子平台的评估
## 结论：放弃迁移
## 原因：
1. 使用扣子平台的免费版本无法使用它的全部功能，而且免费使用次数较少，个人使用一个月所需的费用较高，十分不划算。
2. 生成多层分支和嵌套结构是会受到限制，特别是在工作流中再嵌套多个工作流或者在在object变量中嵌套多个object变量时会出现这类问题
3. 在用工作流实现项目所需的效果时需要对原有代码的内容进行大幅度修改，特别是需要对原有代码不同部分，板块之间的关系结构进行修改。
4. 在使用扣子平台生成与项目类似的“故事生成”ai时存在缺陷，而且使用扣子平台中已有的智能体来代替原有项目中的代码来实现相应功能的方式效果不佳。
